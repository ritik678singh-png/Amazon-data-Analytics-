Example: rank products within category

WITH product_sales AS (
 SELECT Category, ProductName,
        SUM(Quantity * UnitPrice) AS gross_value
 FROM dbo.amazon_sales
 GROUP BY Category, ProductName
),
ranked AS (
 SELECT *, RANK() OVER(
   PARTITION BY Category
   ORDER BY gross_value DESC
 ) AS rnk
 FROM product_sales
)
SELECT Category, ProductName, gross_value
FROM ranked WHERE rnk = 1;

Concepts: CTE, GROUP BY, SUM, RANK and PARTITION BY.

Methodology & limitations

Workflow

  1. Profile data and check key fields.
  2. Load the 20-column dataset into SQL Server.
  3. Analyse KPIs, trends and rankings with SQL.
  4. Summarise results into CSVs and findings.
  5. Prepare DAX measures and BI report design.

Interpretation caveats

  • Dataset is synthetic, not official Amazon data.
  • TotalAmount is recorded transaction amount, not audited net revenue.
  • Quantity × UnitPrice is gross line value, not profit.
  • Costs and margins are unavailable.
  • Some product/category pairings need validation.
